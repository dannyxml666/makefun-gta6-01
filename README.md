# Vice Metropolis

Vice Metropolis is an open-world 3D crime simulation game built with vanilla JavaScript and raw WebGL. Explore the city on foot or in vehicles, complete missions from fixers, evade police chases, and manage your wanted level.

## How to Play

1. Start the local development server:
   ```bash
   node serve.ts
   ```
2. Open your browser at `http://localhost:8080`.
3. Click **NEW GAME** to start playing.

## Controls

- **Movement:** WASD / Arrow Keys
- **Enter/Exit Car / Steal:** E
- **Punch:** F
- **Pause:** P
